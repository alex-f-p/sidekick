# AI Tinkerers Hackathon

## Theme

Agents are leaving the chatbox. Build an agent for a place people already work, talk, or live, then make it meaningfully more useful because of that context. Put it into the web, mobile, Slack, Teams, messaging, browsers, voice, wearables, robotics, or somewhere nobody expects to find one yet. What becomes possible when the agent shows up where the work is already happening?

## The Challenge

Build an agent for a place people already work, talk, or live, then make it meaningfully more useful because of that context.

That could mean the web, mobile, Slack, Teams, messaging, browsers, workplace software, voice, wearables, robotics, or an entirely new environment.

## Build Something Real

The goal is a working prototype that can be demonstrated by the end of the day. Keep the scope tight, prioritize the core interaction, and make sure the agent’s environment is essential to the experience.

You may use any technical stack. The shared starter repository, sponsor resources, credits, and technical documentation will be added here before build day.

## Build Eligibility

Every submitted project must be a net-new build created during the official hackathon period.

Teams may use existing templates, reusable components, libraries, prompts, starter code, or other building blocks. However, the project being submitted and its core functionality must be built during the event. A pre-existing project cannot be resubmitted or extended and entered as a new hackathon project.

Teams should be prepared to explain which parts of their project were created during the hackathon.

## Your Submission

Every team must submit:

1. A project title
2. A written description
3. A public GitHub repository
4. A two-minute demonstration video
5. A social media post about the project tagging the event partners

Every team must complete its submission by the deadline shown in the hackathon portal.

Every eligible project will enter the same global competition.
