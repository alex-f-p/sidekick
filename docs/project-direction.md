# Project Direction

Initial thoughts recorded September 12, 2026. The concept has since developed into an AI teammate for live knowledge-work meetings. See the [PRD](prd.md) for the current direction, agreed requirements, and remaining design decisions. The notes below preserve the initial starting point.

## Requirements

- Use the new OpenAI Agents API.
- Use Exa.
- Use [Ambiguous AI](https://www.ambiguous.ai/).
- Include a major voice element using GPT-Live.
- Build something ambitious and amazing.

## Initial Questions

- The intended users and problem to solve.
- Where the agent operates and why that environment is essential.
- How voice, research, and workspace actions combine into the core experience.
- A focused prototype and two-minute demonstration that show the ambition clearly.
