# Sidekick

An AI teammate that participates in live knowledge-work meetings and creates useful work while the team talks.

Sidekick listens, researches questions, contributes at appropriate moments, and builds shared documents in Ambiguous AI. Teams leave with usable outputs and a record of decisions, pending questions, ambiguities, and follow-ups.

Built for the AI Tinkerers **Agents, Everywhere** hackathon. Sidekick is a working title.

## Status

Product planning and integration preparation. The application has not been implemented yet.

## Planned Integrations

- **GPT-Live:** Natural spoken participation.
- **OpenAI Agents API:** Ongoing work and orchestration.
- **Exa:** External research and supporting information.
- **Ambiguous AI:** Shared workspace, documents, and work records.

## Setup

The local `.env.local` file holds server-side credentials and is ignored by Git. Fill its empty values locally; never paste secrets into documentation or commit them. `.env.example` lists the required credential names for other checkouts.

See [setup readiness](docs/setup-readiness.md) for outstanding account and integration checks. There is no application start command yet.
